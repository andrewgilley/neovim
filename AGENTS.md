# Project instructions

- After making Lua edits, run the Neovim `:LuaParagraphFormat` command on the edited
  Lua files/buffers before committing (e.g. `nvim --headless "+edit <file>" "+LuaParagraphFormat" "+w" +q`), then review the diff.

- Once you have completed the task the user asked for and formatted the files, commit the
  intended changes with a minimal, concise commit message and push them to the remote.
